# Typescript

This directory contains category specific typescript/js packages, making integration development easier.
The source code is generated by running `mise run generate`.
To add a new category:

1. Ensure the schema exists in the [schemas directory](../../schemas/).
2. Copy one of the existing package directories and rename the directory to be the same as your target schema.
3. Open the `package.json` file, rename the package, and set the version.
4. Run `mise run generate`.
